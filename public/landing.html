One saved change reaches every open board

The change and its event are written in one database transaction. PostgreSQL then tells every web server, and each one streams the event to the people allowed to see it.

  • A browser that drops off replays up to 500 missed events.
  • An event a crashed request left behind is sent by the worker.
  • A failing delivery retries 8 times before it is set aside.

Can I host Fellow myself?

Yes. One docker compose command starts PostgreSQL, two web servers behind nginx and the outbox worker.

What if two people edit one board card?

The first save wins. The second is refused with the newer version, so nothing is overwritten without anyone noticing.

Does board sync work across servers?

Yes. Every web server listens to PostgreSQL, so a card moved through one server shows on boards connected to another.

Does Fellow have an API?

Yes. The app runs on the same versioned REST API, described in OpenAPI on the docs page.

What does Fellow leave out?

Gantt charts, time tracking and a mobile app. It is boards, tasks, comments, roles and notifications.
